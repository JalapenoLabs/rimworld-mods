# Synced Storyteller

A RimWorld mod for playing the same story side by side. Two games started
from the same world seed get the same storyteller events on the same days,
no matter how differently each colony is run.

## How it works

RimWorld draws nearly all randomness from one global stream (`Verse.Rand`).
Pawn AI, combat, plant growth, weather, and the storyteller all pull from it,
so two identical starts drift apart the moment the players do anything
differently.

This mod gives the storyteller its own seeded dice in the two places it rolls:

| Hook | What it decides |
| --- | --- |
| `StorytellerComp.MakeIntervalIncidents` (every override) | Whether an event happens this interval, its category, and which incident |
| `Storyteller.TryFire` | How the incident plays out: raid faction, strategy, arrival, spawn point, quest contents |

Each seed combines the world's `persistentRandomValue` (fixed by the seed
string), the current tick, the incident target, and the comp or incident.
It is rebuilt from scratch every time, so one difference between the
colonies (a caravan out, an event that could not fire) cannot shift any
other roll.

Vanilla already times Cassandra's and Phoebe's threat cycles from the world
seed. This mod extends that to everything else the storyteller decides.

## Staying in sync

Both players need:

- the same mod list, in the same load order
- the same world seed, scenario, and starting tile
- the same storyteller and difficulty, never changed mid-game

## What still diverges

- **Threat size.** Raid points scale with each colony's wealth and
  population. Both colonies get the raid on day 12, but the richer one gets a
  bigger raid.
- **Preconditions.** An event that needs something one colony lacks (a
  prisoner, animals nearby) is skipped for that colony only.
- **Population weighting.** Wanderer joins and refugee events are weighted by
  colonist count, so their odds shift as the colonies grow apart.
- **Quest-driven threats.** Threats generated by active quests depend on
  which quests each player accepted.

## Comparing runs

With dev mode on, every storyteller fire is logged:

```text
[Synced Storyteller] Tick 720000: RaidEnemy on Map-0-PlayerHome fired.
```

Diff the two players' logs to see where the stories matched and where they
split. To check the mod alone, load one save twice, play each copy
differently for a few days, and compare the logs.

## Building

From the monorepo root:

```shell
mage build synced-storyteller
```

The compiled assembly is written to `1.6/Assemblies/SyncedStoryteller.dll`.
