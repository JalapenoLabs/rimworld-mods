# Tiered Gravship Shields

Adds tier 2 and tier 3 gravship shield generators for the Odyssey DLC. The vanilla shield generator becomes tier 1. Higher tiers offer greater shield capacity at proportionally higher power draw, and are obtainable only as rare quest rewards.

| Tier | Shield Capacity | Power Draw |
|------|----------------|------------|
| 1 (vanilla) | 1× | 1× |
| 2 | 2× | 2× |
| 3 | 4× | 4× |

XML-only mod — no C# required.

## Building / installing

This mod is part of the [rimworld-mods monorepo](https://github.com/JalapenoLabs/rimworld-mods). Clone the monorepo and drop the `tiered-gravship-shields` folder into your RimWorld `Mods/` directory.
